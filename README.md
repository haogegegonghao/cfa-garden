# CFA 小花园

给大方的 CFA Level I 备考小网站：倒计时、学习计划、知识地图、公式闪卡、练习题和学习花园。

## 怎么写一张新纸条

在 GitHub 上打开 `notes.json`，点右上角的铅笔图标编辑，在 `"notes"` 里加一条，然后点 **Commit changes**。一两分钟后网站就会更新，最新日期的那张会显示在首页。

```json
"notes": [
  { "date": "2026-11-26", "text": "今天也辛苦啦，学完早点睡。" },
  { "date": "2026-11-25", "text": "第一天，加油。" }
]
```

每条之间用英文逗号隔开，最后一条后面不加逗号。`rewards` 是里程碑奖励，`herName` 是首页问候里的称呼。

学习进度保存在她自己浏览器里，可以在「学习计划」页底部下载备份。
